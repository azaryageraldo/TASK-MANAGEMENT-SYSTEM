STUDI KASUS: TASK MANAGEMENT SYSTEM

Deskripsi Umum
Perusahaan membutuhkan sistem untuk membantu karyawan mengatur dan
memonitor tugas harian mereka.


FITUR YANG HARUS DIBANGUN

1. Autentikasi Pengguna
- Login dan Register menggunakan email & password
- Password harus di-hash (gunakan bcrypt atau library sejenis)
- Autentikasi berbasis JWT Token
- Kolom login:
  user_id, name, username, password

2. Manajemen Task
- Fitur CRUD (Create, Read, Update, Delete) task
- Kolom task:
  task_id, user_id, title, description, status, deadline, created_by
- Status task:
  To Do, In Progress, Done

3. Filter dan Sorting
- Filter task berdasarkan status
- Sorting task berdasarkan tanggal deadline

4. Frontend Interface
- Tampilkan daftar task
- Form untuk membuat dan mengedit task
- Filter dropdown berdasarkan status
- UI sederhana tapi responsif
  (gunakan TailwindCSS atau Bootstrap)

5. Keamanan
- Semua endpoint task hanya bisa diakses oleh user yang login
- Tidak boleh ada task milik user lain yang bisa dibaca atau diedit


PERSYARATAN TEKNIS

Backend:
- Gunakan salah satu:
  Laravel / NestJS / ExpressJS / GoFiber / Lainnya

Frontend:
- Gunakan salah satu:
  ReactJS / VueJS / NextJS / Lainnya

Database:
- MySQL atau PostgreSQL
- Simpan database dalam bentuk dump (db.sql)

ORM / Query Builder:
- Disarankan menggunakan ORM
  (Eloquent, TypeORM, Gorm)

Autentikasi:
- JWT (JSON Web Token)

Dokumentasi API:
- Gunakan Postman Collection atau Swagger

Environment:
- Sertakan file .env.example

Deployment (Opsional):
- Bisa dijalankan via Docker Compose (bonus poin)

Source Control:
- Gunakan GitHub atau GitLab
- Commit harus bertahap (tidak satu kali upload besar)
- Gunakan commit message yang bermakna
